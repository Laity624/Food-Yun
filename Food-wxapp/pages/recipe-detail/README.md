# 菜谱详情页

## 📖 功能概述

菜谱详情页是Food-Yun家庭菜谱小程序的核心页面之一，提供完整的菜谱展示和制作辅助功能。

## 🎯 主要功能

### 1. 沉浸式展示
- **头图轮播**：支持多张菜谱图片展示
- **渐变遮罩**：确保文字内容的可读性
- **毛玻璃效果**：现代化的导航按钮设计
- **核心信息卡片**：突出显示菜谱名称、描述和关键数据

### 2. 分类标签系统
- **场景分类**：日常、快手、宴客、清淡、重口味
- **食材分类**：肉类、水产、蛋类、蔬菜、汤类、主食
- **可选标签**：烹饪方式和口味特色
- **点击筛选**：支持点击标签跳转到筛选页面

### 3. 制作信息展示
- **制作时间**：分钟数显示
- **难度等级**：简单/中等/困难
- **适合人数**：人份数显示
- **网格布局**：清晰的信息组织

### 4. 制作辅助功能
- **食材清单**：支持查看模式和制作模式切换
- **步骤指导**：图文并茂的制作步骤
- **勾选功能**：制作时可勾选已准备的食材和已完成的步骤
- **进度跟踪**：完成所有步骤时显示庆祝弹窗

### 5. 社交功能
- **收藏功能**：本地存储收藏状态
- **分享功能**：支持分享给好友、朋友圈、复制链接
- **评价系统**：星级评分和评价统计
- **创建者信息**：显示菜谱创建者信息

## 🎨 设计特色

### 视觉设计
- **沉浸式头图**：560rpx高度，营造视觉冲击力
- **卡片式布局**：圆角设计，层次分明
- **渐变色彩**：统一的色彩系统
- **响应式适配**：支持不同屏幕尺寸

### 交互设计
- **模式切换**：查看模式和制作模式
- **触觉反馈**：勾选时的震动反馈
- **动画效果**：流畅的过渡动画
- **状态持久化**：制作进度本地保存

## 🔧 技术实现

### 文件结构
```
pages/recipe-detail/
├── recipe-detail.wxml    # 页面结构
```

### 核心功能
1. **数据加载**：云函数获取菜谱详情
2. **图片处理**：懒加载和预览功能
3. **状态管理**：制作模式和勾选状态
4. **本地存储**：收藏状态和制作进度

- **图片懒加载**：减少初始加载时间
- **数据缓存**：避免重复请求
- **动画优化**：使用CSS3硬件加速
- **滚动优化**：流畅的滚动体验

## 📱 使用方法

### 页面跳转
```javascript
wx.navigateTo({
  url: `/pages/recipe-detail/recipe-detail?id=${recipeId}`
})
```

### 数据格式
```javascript
{
  _id: "recipe_id",
  name: "菜谱名称",
  description: "菜谱描述",
  images: ["图片URL数组"],
  ingredients: [
    {
      id: "ingredient_id",
      name: "食材名称",
      amount: "用量",
      checked: false
    }
  ],
  steps: [
    {
      id: "step_id",
      content: "步骤内容",
      image: "步骤图片URL",
      completed: false
    }
  ],
  // ... 其他字段
}
```

## 🎭 交互流程

### 查看模式
1. 用户进入页面，查看菜谱信息
2. 可以点击标签进行筛选
3. 可以收藏和分享菜谱
4. 可以查看制作步骤和食材清单

### 制作模式
1. 点击"开始制作"按钮
2. 切换到制作模式
3. 勾选已准备的食材
4. 按步骤制作，标记完成的步骤
5. 完成所有步骤时显示庆祝弹窗
